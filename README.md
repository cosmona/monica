# Monica

Tarjeta de felicitación web por el nacimiento de un bebé: **«¡Coronada como Reina de las mamis!»**. Es una página estática con un mensaje personalizado.

## Cómo verla

Abre `index.html` en el navegador. No necesita instalar nada.

## Estructura

```
index.html
index.css
```

Hecha a partir de la misma plantilla que [Marina](https://github.com/cosmona/Marina).
